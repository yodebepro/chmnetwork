CHM Network GitHub Pages deployment

This package contains a GitHub Actions workflow that deploys the website automatically.

Required GitHub setting:
1. Open the repository on GitHub.
2. Go to Settings > Pages.
3. Under Build and deployment, set Source to GitHub Actions.
4. Return to the Actions tab and wait for 'Deploy CHM Network to GitHub Pages' to finish.
5. In Settings > Pages > Custom domain, enter chmnetwork.com and save.

DNS requirements for chmnetwork.com:
- Apex A records must point to GitHub Pages IP addresses.
- Remove conflicting A, AAAA, or CNAME records.
- The CNAME file is already included in this package.

The website files, TV, radio, store, contact form, and admin controls were not changed.
